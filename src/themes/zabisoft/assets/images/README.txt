Graphics in this folder
=======================

Everything shipped with this theme was produced for this project:

* screenshot.png – a rendering of the theme design, generated with ImageMagick
  (see tools/make-images.sh in the repository). No screenshot of any other
  website is used.
* placeholder.svg – a hand written SVG placeholder shown when an entry has no
  featured image.

No icons, photographs or program logos from third parties are bundled. The
interface icons are inline SVG symbols written for this theme (see
inc/template-tags.php), so they inherit the text colour and need no extra
licence.

If you add your own images, remember that publishers' logos and box shots are
protected: only add material you own or that is licensed to you, and write the
source in the image caption or alt text.
