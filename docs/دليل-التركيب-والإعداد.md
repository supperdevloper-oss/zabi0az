# دليل التركيب والإعداد — قالب وإضافة ZabiSoft

موقع برامج جاهز على ووردبريس: قالب حقيقي (Theme) بلغة PHP + إضافة مستقلة لإدارة البرامج
وروابط التحميل. لا تحتاج إلى أي معرفة برمجية: كل شيء يُدار من لوحة تحكم ووردبريس.

---

## 1. الملفات التي بين يديك

| الملف | ما هو | أين يُركَّب |
| --- | --- | --- |
| `zabisoft-1.0.0.zip` | القالب (التصميم والصفحات) | المظهر ← القوالب ← أضف جديد ← رفع قالب |
| `zabisoft-software-manager-1.0.0.zip` | الإضافة (البرامج، التصنيفات، روابط التحميل) | إضافات ← أضف جديد ← رفع إضافة |

> مهم: ركّب **الاثنين**. القالب يعرض المعلومات، والإضافة هي التي تنظّمها وتفحص روابط التحميل.
> إن ركّبت القالب وحده سيعمل الموقع، لكن قسم «البرامج» سيكون ناقصًا.

---

## 2. المتطلبات (شروط يجب توفرها قبل التركيب)

* ووردبريس **6.4** أو أحدث (تم اختبار الحزمة على ووردبريس 7.1).
* **PHP 7.4** أو أحدث (يُفضَّل 8.1+).
* **MySQL / MariaDB** — أي استضافة ووردبريس عادية تكفي.
* إضافة PHP للصور **GD أو Imagick** (موجودة افتراضيًا في كل الاستضافات تقريبًا) حتى يعمل
  تصغير الصور المصغّرة.
* صلاحية **مدير (Administrator)** في لوحة التحكم.
* لا تحتاج إلى أي إضافة إضافية، ولا إلى أي مكتبة خارجية أو خطوة بناء (npm/Composer).

---

## 3. طريقة التركيب الأولى: من لوحة تحكم ووردبريس (الأسهل)

1. ادخل إلى لوحة التحكم: `https://yoursite.com/wp-admin`.
2. **تركيب القالب**: المظهر ← القوالب ← «أضف جديد» ← «رفع قالب» ← اختر
   `zabisoft-1.0.0.zip` ← «تركيب الآن» ← **تفعيل**.
3. **تركيب الإضافة**: إضافات ← «أضف جديد» ← «رفع إضافة» ← اختر
   `zabisoft-software-manager-1.0.0.zip` ← «تركيب الآن» ← **تفعيل**.
4. **مهم جدًا**: الإعدادات ← الروابط الدائمة ← اختر «اسم المقالة»
   (`https://yoursite.com/%postname%/`) ← **حفظ التغييرات**.
   هذه الخطوة ضرورية لتعمل روابط التصنيفات والبرامج (`/softwares/…` و `/office-tools/`).
5. افتح **المظهر ← تخصيص** واضبط الشعار، الألوان، ونصوص الصفحة الرئيسية.

## 4. طريقة التركيب الثانية: عبر cPanel أو FTP

1. من **cPanel** افتح «File Manager» (مدير الملفات) أو اتصل بالسيرفر عبر FTP.
2. ادخل إلى مجلد الووردبريس ثم إلى `wp-content/themes`.
   * ارفع ملف `zabisoft-1.0.0.zip` ثم اضغط عليه بزر الفأرة الأيمن واختر **Extract**.
   * تأكد أن الملفات أصبحت داخل `wp-content/themes/zabisoft/` (وأن `style.css` موجود
     مباشرة في هذا المجلد، وليس داخل مجلد فرعي إضافي).
3. ادخل إلى `wp-content/plugins` وكرّر نفس العملية مع
   `zabisoft-software-manager-1.0.0.zip` بحيث يصبح المسار
   `wp-content/plugins/zabisoft-software-manager/`.
4. احذف ملفَي الـ zip بعد فك الضغط (اختياري لكن أفضل).
5. ارجع إلى لوحة التحكم: المظهر ← القوالب ← فعّل **ZabiSoft**، ثم إضافات ← فعّل
   **ZabiSoft Software Manager**.
6. الإعدادات ← الروابط الدائمة ← «اسم المقالة» ← حفظ التغييرات.

## 5. الإعداد الأول (خمس دقائق تكفي)

### 5.1 القوائم
المظهر ← القوائم:
* أنشئ قائمة باسم «Main menu» وأضف إليها: الرئيسية، التصنيفات المهمة (أنظمة التشغيل،
  أدوات المكتب، مضادات الفيروسات…)، ثم عنصر «اتصل بنا».
* من أسفل الصفحة اختر مكان العرض: **Primary (القائمة الرئيسية)**.
* أنشئ قائمة ثانية «Footer menu» وضع فيها: من نحن، اتصل بنا، سياسة الخصوصية،
  إخلاء المسؤولية، DMCA، خريطة الموقع، ثم اختر مكان العرض **Footer**.

### 5.2 القوالب والصفحات الثابتة
عند إنشاء أي صفحة جديدة ستجد في العمود الجانبي صندوق **«قالب الصفحة»**، اختر منه:

| الصفحة | القالب المناسب |
| --- | --- |
| من نحن | About page |
| اتصل بنا | Contact page (يحتوي نموذج تواصل جاهز + نموذج الحماية من السبام) |
| خريطة الموقع | Sitemap page |
| أي صفحة بدون شريط جانبي | Full width (no sidebar) |

سياسة الخصوصية وإخلاء المسؤولية و DMCA: صفحات عادية، يُنصح بتركها بدون شريط جانبي
أو بالقالب «Full width».

### 5.3 إعدادات الإضافة
القائمة الجانبية ← **البرامج ← الإعدادات**:

* **Archive URL slug**: الافتراضي `softwares` (روابط البرامج تصبح `/softwares/اسم-البرنامج/`).
* **Category URL base**: اتركه **فارغًا** لتصبح روابط التصنيفات نظيفة مثل `/office-tools/`.
  إذا كان لديك صفحة بنفس العنوان، اكتب مثلًا `category` ليصبح `/category/office-tools/`.
* **Entries per archive page**: عدد البرامج في كل صفحة (الافتراضي 10).
* **Default countdown**: مدة العد التنازلي قبل ظهور زر التحميل (بالثواني، 0 = بدون عد).
* **Check every mirror URL when an entry is saved**: فحص تلقائي للروابط عند الحفظ.
* **Re-check all links every 12 hours**: فحص دوري عبر WP-Cron.
* **Disclosure text**: الجملة التنبيهية التي تظهر أسفل صندوق التحميل.
* بعد تغيير الـ slug أو الـ base: احفظ الإعدادات ثم الإعدادات ← الروابط الدائمة ← حفظ.

## 6. إضافة برنامج جديد (خطوة بخطوة)

1. **البرامج ← أضف جديد**.
2. اكتب الاسم في العنوان، وضع وصفًا كاملًا في المحرر (سيظهر كقسم «نظرة عامة»).
3. **الصورة البارزة** (العمود الأيمن): صورة غلاف البرنامج (يُفضّل 800×500).
4. من الصندوق الجانبي اختر **التصنيف** و**المنصة** (ويندوز، ماك، لينكس…).
5. املأ صندوق **تفاصيل البرنامج**: الإصدار، حجم الملف، اسم ملف التثبيت، نوع التثبيت،
   التوافق، الترخيص، آخر تحديث، المطوّر، الموقع الرسمي، اللغات.
   * الحقول المتروكة فارغة لا تظهر في الجدول.
6. **متطلبات التشغيل**: نظام التشغيل، المعالج، الذاكرة، القرص، كرت الشاشة.
7. **الميزات وتعليمات التثبيت**: سطر لكل ميزة، وسطر لكل خطوة تثبيت.
8. **لقطات الشاشة**: اضغط «Add screenshots» واختر الصور من مكتبة الوسائط.
9. **روابط التحميل (Download mirrors)**:
   * لكل رابط سطر مستقل: التسمية، الرابط، الحجم، النوع، المنصة، ملاحظة.
   * زر **Check link** يخبرك فورًا إن كان الرابط يعمل.
   * يمكنك إضافة عدة نسخ (موقع رسمي، نسخة محمولة، نسخة 32 بت…).
   * الرابط يجب أن يبدأ بـ `https://` (أو `http://`).
10. **العد التنازلي**: اتركه فارغًا للقيمة العامة، أو اكتب مدة خاصة بهذا البرنامج،
    أو `0` لإطفائه.
11. **انشر** ثم اضغط «معاينة»: يتم توليد فهرس المحتويات، جدول المواصفات، المتطلبات،
    معرض الصور، صندوق التحميل، ثم البرامج المشابهة **تلقائيًا**.

### ملاحظة قانونية مهمة
لا ترفع ملفات التثبيت (`exe/msi/dmg`) ولا تضف روابط لملفات لا تملك حق توزيعها.
الصح هو ربط **صفحة المطوّر الرسمية**: الحزمة تطبع اسم المضيف بجانب كل زر، وتضيف
`rel="nofollow noopener"`، ويمكنك كتابة تنبيه واضح أسفل صندوق التحميل.
أيضًا: شعارات البرامج التجارية وصور أغلفتها محمية بحقوق الملكية — استخدم صورًا تملكها
أو صورًا مرخّصة لك.

## 7. إدارة التصنيفات والمنصات

* **البرامج ← التصنيفات**: أنشئ تصنيفات مثل: أنظمة التشغيل، أدوات المكتب، تحرير الفيديو،
  التصميم ثلاثي الأبعاد، الحماية ومضادات الفيروسات، استعادة البيانات، أدوات التنزيل،
  أدوات الأقراص. أي تصنيف فرعي يظهر داخل التصنيف الأب.
* **البرامج ← المنصات**: ويندوز، ماك، لينكس، أندرويد، آي أو إس (تظهر كشارات في صفحة
  البرنامج وتُستخدم للتصفية).
* **البرامج ← الوسوم**: كلمات مفتاحية حرة.

---

## 8. الودجات والشريط الجانبي

* المظهر ← الودجات: لديك أماكن جاهزة:
  `sidebar-1` (الشريط الجانبي)، `front-page` (الصفحة الرئيسية)،
  و `footer-1 … footer-4` (أعمدة التذييل).
* الودجات الافتراضية في القالب: آخر البرامج، التصنيفات، كلمات شائعة، نموذج بحث،
  بطاقة تعريف، ومقالات حديثة.
* صفحة «المظهر ← تخصيص ← Sidebar» تسمح بإظهار أو إخفاء الشريط الجانبي في الصفحات
  والمقالات والتصنيفات.

## 9. المحتوى التجريبي (اختياري ومفيد للبداية)

البرامج ← الإعدادات ← قسم Demo content:

* **Import demo content**: يُنشئ 6 برامج كاملة (صور + مواصفات + روابط لمواقع المطوّرين
  الرسمية)، وصفحات: من نحن، اتصل بنا، سياسة الخصوصية، إخلاء المسؤولية، DMCA،
  خريطة الموقع، ومقالتين، وقائمتي «Main menu» و«Footer menu».
  كل الصور المرفقة **من تصميم هذه الحزمة** ولا تحتوي أي شعار لبرنامج آخر.
* **Remove demo content**: يحذف كل ما أنشأته الإضافة، دون المساس بمحتواك الخاص.
* ما لم تنقر الاستيراد، لن تُنشأ أي بيانات تجريبية تلقائيًا.

## 10. الأسئلة الشائعة وحل المشاكل

**التصنيفات أو صفحات البرامج تظهر «الصفحة غير موجودة» (404).**
اذهب إلى الإعدادات ← الروابط الدائمة ← «اسم المقالة» ← حفظ التغييرات. هذا يُعيد بناء
قواعد الروابط. إن استمرت المشكلة، عطّل الإضافة ثم فعّلها مرة أخرى ثم أعد الحفظ.

**عنوان التصنيف يتعارض مع صفحة عندي.**
البرامج ← الإعدادات ← **Category URL base** ← اكتب `category` مثلًا ← حفظ، ثم أعد حفظ
الروابط الدائمة. ستصبح `/category/office-tools/`.

**فحص الروابط يفشل دائمًا.**
بعض المواقع ترفض الطلبات الآلية (403) أو تحجب الاستضافة. تحقّق من الرابط بنفسك في
المتصفح؛ النتيجة المخزّنة تُحدَّث كل ساعة. يمكن تعطيل الفحص التلقائي من الإعدادات.

**النموذج في صفحة «اتصل بنا» لا يرسل رسالة.**
يستخدم النموذج دالة البريد في ووردبريس. إن لم يعمل بريد موقعك، ركّب إضافة SMTP
(مثل WP Mail SMTP) أو اربط البريد بخدمة الاستضافة.

**القالب لم يظهر في قائمة القوالب بعد الرفع عبر cPanel.**
تأكد من أن الملفات مباشرة داخل `wp-content/themes/zabisoft/` وأن `style.css` بينها،
ثم أعد تحميل صفحة القوالب.

**هل يظهر الموقع بشكل صحيح على الجوّال؟**
نعم، القالب متجاوب بالكامل عند 1080px و 860px و 640px، ويحتوي ملف `rtl.css` لعرض
المواقع العربية من اليمين إلى اليسار (يكفي تشغيل ووردبريس بالعربية).

**هل الحزمة متوافقة مع إضافات SEO؟**
نعم، القالب لا ينشئ وسوم SEO مكرّرة، ويعمل مع Yoast أو Rank Math أو SEOPress.
أضف خريطة موقع من إضافة SEO، أو استخدم خريطة ووردبريس الجاهزة `/wp-sitemap.xml`.

**الأمان والصيانة.**
لا توجد كلمات مرور أو مفاتيح داخل ملفات القالب. كل المدخلات تُنظَّف (`sanitize_*`)
وكل المخرجات تُهرَّب (`esc_*`)، ونماذج الإضافة محمية بـ nonce وصلاحيات المستخدم.
خذ نسخة احتياطية قبل تحديث ووردبريس أو الإضافات، واحتفظ بالحزمة كما هي للرجوع إليها.

## 11. تخصيص الهوية

* **المظهر ← تخصيص ← Colors**: خمس لوحات ألوان جاهزة (أخضر، أزرق، أحمر، برتقالي، بنفسجي)
  أو اختر ألوانك الخاصة (اللون الأساسي، لون التمرير، لون الأزرار).
* **Typography**: نوع الخط وحجمه للعناوين والنص.
* **Front page**: نص العنوان الفرعي، أزرار الوصول السريع، عدد البرامج المعروضة،
  إظهار/إخفاء شريط التصنيفات.
* **Footer**: نص حقوق النشر، روابط التواصل، عدد الأعمدة.
* استبدال الشعار: المظهر ← تخصيص ← Site Identity ← الشعار (الأبعاد المناسبة 300×70).

## 12. قائمة تحقّق سريعة قبل النشر

- [ ] القالب مفعّل والإضافة مفعّلة.
- [ ] الروابط الدائمة مضبوطة ومحفوظة مرة واحدة.
- [ ] القوائم مربوطة بمواضعها (Primary / Top bar / Footer).
- [ ] الصفحات الأساسية موجودة: من نحن، اتصل بنا، الخصوصية، إخلاء المسؤولية، DMCA،
      خريطة الموقع.
- [ ] كل برنامج له صورة، مواصفات، متطلبات، وميزة واحدة على الأقل.
- [ ] كل رابط تحميل تم فحصه بالأزرار «Check link» أو بزر الفحص الجماعي.
- [ ] جرّبت الموقع من الجوّال ومن الحاسب، ومن صفحة البحث، ومن الترقيم (1، 2، 3…).
- [ ] جرّبت فتح صفحة غير موجودة للتأكد من ظهور صفحة 404 بشكل صحيح.
